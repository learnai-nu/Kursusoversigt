## Findings (prioritized)

### High

1. **Demo trust leak on production**  
   Homepage still shows “Demo-mode kører på lokal JSON…”. Footer says “Demo-data” and links “Admin (demo)”.  
   - Observation: undermines E-E-A-T and click trust in SERP/snippet.  
   - Unblocks: brand credibility + lead conversion.  
   - Failure signal: bounce/lead rate weak despite impressions.  
   - Leading indicator: demo strings gone from production HTML.

2. **Canonical trailing-slash mismatch**  
   Course/article/provider URLs resolve **without** slash (200), but canonical often **with** slash. Both slash variants return 200 (no redirect).  
   - Observation: split signals / soft duplicates.  
   - Unblocks: cleaner indexation consolidation.  
   - Failure signal: GSC “Duplicate without user-selected canonical”.  
   - Leading indicator: one URL form 308→other; canonical matches final URL.

3. **Missing E-E-A-T surfaces**  
   No `/om`, metode beyond one article, author bios (bylines like “Mette Ravn” without person pages).  
   - Observation: directory + editorial claims need accountable publisher story.  
   - Unblocks: YMYL-adjacent trust (education).  
   - Failure signal: low engagement on articles vs catalog.  
   - Leading indicator: `/om` + metode indexed; author consistency policy.

### Medium

4. **No `og:image` / social preview asset** — weaker shares and some AI/citations UX.  
5. **Catalog HTML heavy** (`/ai-kurser` ~91 KB) + Google Fonts CDN — watch LCP/INP once CWV measured.  
6. **Provider pages thin** relative to course/article pages — unique intros still thin for many providers.  
7. **`last_verified` aging** (many 2026-09-05) — freshness risk for directory usefulness.  
8. **Homepage featured set** currently skews alphabetically toward global academies — weak for “AI-kurser Danmark” intent.  
9. **Admin linked in footer** while robots disallows — still a crawl hint; remove from public chrome.

### Low / Info

10. Almost no content images (Images pillar low; also less CLS risk).  
11. Do **not** add FAQPage for Google SERP gains (retired).  
12. No field Core Web Vitals in this audit — measure in GSC/CrUX next.  
13. Search Console is connected (user) — rankings/impressions not pulled here (no invented metrics).

## Sequenced actions (dependency order)

1. Remove production demo copy + footer “Admin (demo)” / “Demo-data” wording  
2. Normalize trailing slashes (pick one; redirect the other; align `absoluteUrl` + canonical)  
3. Add `/om` (+ short metode) and og:image defaults  
4. Reorder homepage featured courses toward DK commercial intent  
5. Weekly catalog verification pass (prices/links/`last_verified`)  
6. Continue content plan week 4+ *after* 1–3  
7. Pull GSC coverage + query report in 2–4 weeks for the next audit
